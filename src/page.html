This page runs entirely on your machine. Disconnect from the network first if you like; recovery does not need it. Your 24 words stay in this tab.

Your 24 words

A key minted before the standard-paths ruling has v1 addresses; a key minted after has v2. Send only to the set your key actually owns — the two are different addresses and money sent to the wrong one is not yours to move.

Balance (optional — an endpoint you name)

There is no default endpoint and no ONE server is used. Type a public node you trust; only the public address above is sent to it.

This file carries its own code — there is nothing beside it to lose and nothing to fetch. It is built offline with bun run build:page in packages/recover, and the derivation is written down in text/key-derivation-spec.md — anyone can reimplement this from that page alone.
